## Kinds of codes
Bills use codes to identify services. CPT codes are five-digit codes for procedures and visits. HCPCS Level II codes start with a letter followed by four digits and cover items such as drugs, supplies, and ambulance services. Hospital bills often also use three- or four-digit revenue codes that name a department, such as the emergency room or pharmacy. Diagnosis codes (ICD-10) describe why you received care.

## Modifiers
A code can have a two-character modifier after it, such as 25 or LT. Modifiers add details, for example that a service was separate from another one done the same day, or which side of the body was treated. The same code with different modifiers can be correct, such as one procedure on the left side and one on the right.

## If a code does not look right
If a code or description does not match the care you remember, ask the billing office what the code is for and why it was used. Coding mistakes are a common reason for claim denials and wrong charges.
